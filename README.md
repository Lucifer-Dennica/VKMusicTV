# VideoDownloader

Android-приложение на Kotlin, Jetpack Compose и Material 3 для сохранения разрешённых пользователем публичных видео и просмотра их офлайн. Проект использует MVVM, Room, WorkManager, Media3 и Storage Access Framework.

## Поддерживаемый сценарий

Приложение принимает ссылку через поле или системное меню «Поделиться», определяет домен и ставит загрузку в очередь. В безопасной сборке фактическая загрузка выполняется только для прямых публичных HTTP(S)-ссылок на медиафайл (`.mp4`, `.webm`, `.mov`). Страницы YouTube, TikTok и Instagram требуют официального экспорта или API и не скачиваются как веб-страницы.

Приложение не поддерживает cookies для приватных видео, обход ограничений, DRM, удаление водяных знаков или получение скрытых аудиоссылок. Пользователь отвечает за права на загружаемый контент.

## Сборка

Откройте репозиторий на GitHub и запустите `Actions → Build APK → Run workflow`. APK появится в артефактах запуска. Для локальной сборки нужен JDK 17 и Android SDK API 35: `gradle :app:assembleDebug`.
